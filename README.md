# 🐧 My i3wm Dotfiles

A personal collection of configuration files (dotfiles) for the i3 window manager. This setup focuses on minimalism, productivity, and a clean aesthetic.

## 🖥️ System Overview
* **OS:** Debian GNU/Linux 13 (trixie)
* **WM:** i3-wm
* **Bar:** Polybar
* **Terminal:** Alacritty
* **Shell:** Zsh / Oh My Zsh
* **Compositor:** Picom
* **Launcher:** Rofi
